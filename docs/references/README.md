# Reference images

These images are mood, density, and screen-flow references generated during product exploration. They are not production assets and must not be sliced into the shipping application.

Production art constraints:

- one 2:1 isometric projection;
- one shadow direction;
- fixed pixel scale and integer enlargement;
- limited local glow;
- reusable object, weather, and connector layers;
- Korean interface text rendered as native text, not baked into images.
